# todoi.org — static website

> **No longer in use since 2026-11-12.** todoi.org is now served from
> [`todoi-org-react/`](../todoi-org-react/). This folder is the earlier static site, kept for
> reference: changes made here do not reach the website.

A dependency-free directory comparing browser-based task managers, scored on six criteria with a written justification for each score.

Listing criteria: usable in a browser, and open or partly open source.

Some entries were researched more deeply than others; a `Confidence` value on each row says which.
