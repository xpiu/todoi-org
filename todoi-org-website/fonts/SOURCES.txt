Typefaces — provenance
======================

Two families, both under the SIL Open Font License 1.1 (full text in OFL.txt),
downloaded from the Google Fonts CDN and served from this origin. Nothing is
modified: each file is the woff2 Google Fonts build for that subset, so the
unicode-range in style.css matches the file it guards. The page makes no
third-party font request.

DM Sans is a variable font — one file covers every weight the page uses, and
it carries an optical-size axis (opsz 9–40) that `font-optical-sizing: auto`
drives from the font-size. DM Mono ships static weights, and the three here
are the three the design system actually sets (300 / 400 / 500), so no weight
is ever synthesised.

Earlier revisions set Newsreader for display and Inter for text; both were
replaced by DM Sans on 2026-11-09 so the page runs one grotesk beside its mono.

Replacing a family means replacing its @font-face block in style.css §00 and the
--font-* token in §01 together: the fallback stacks are ordered so the page still
reads in the same two voices if a file is missing, not so a swap can be half
done.
