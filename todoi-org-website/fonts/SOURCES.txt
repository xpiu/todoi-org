Typefaces — provenance
======================

Three families, all under the SIL Open Font License 1.1 (full text in OFL.txt),
downloaded from the Google Fonts CDN on 2026-09-17 and served from this origin.
Nothing is modified: each file is the woff2 Google Fonts builds for that subset,
so the unicode-range in style.css matches the file it guards. The page makes no
third-party font request.

Newsreader and Inter are variable fonts — one file covers every weight the page
uses. DM Mono ships static weights, and the three here are the three the design
system actually sets (300 / 400 / 500), so no weight is ever synthesised.

Replacing a family means replacing its @font-face block in style.css §00 and the
--font-* token in §01 together: the fallback stacks are ordered so the page still
reads in the same three voices if a file is missing, not so a swap can be half
done.
